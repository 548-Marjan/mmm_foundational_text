### Task 3: Rung 3 (Kalman filter) + Proof P1 (keystone)

**Files:** Modify `parts/05-mmm-modeling/03-dlm.qmd`

- [ ] **Step 1: Write Rung 3 — the Kalman filter.** The forward recursion that turns the prior $\mathcal N(m_{t-1},C_{t-1})$ into the filtered posterior $\mathcal N(m_t,C_t)$ in two steps: **predict** (push the state through the evolution equation) then **update** (condition on the new observation). State that it delivers the exact Gaussian filtering posterior $p(\theta_t\mid y_{1:t})$ in closed form when $(V,W)$ are known.

- [ ] **Step 2: Write Proof P1 — Kalman filter = exact Gaussian conditioning (keystone).** State as a proposition and prove by induction on $t$. Provide the full derivation:
  - **Inductive hypothesis.** $\theta_{t-1}\mid y_{1:t-1}\sim\mathcal N(m_{t-1},C_{t-1})$.
  - **Predict.** Applying the linear evolution $\theta_t=G_t\theta_{t-1}+w_t$ to a Gaussian gives $\theta_t\mid y_{1:t-1}\sim\mathcal N(a_t,R_t)$ with
  $$
  a_t = G_t m_{t-1}, \qquad R_t = G_t C_{t-1} G_t^\top + W_t.
  $$
  - **Joint of state and next observation.** Since $y_t=F_t^\top\theta_t+v_t$ is linear-Gaussian in $\theta_t$, the pair is jointly Gaussian given $y_{1:t-1}$:
  $$
  \begin{bmatrix}\theta_t\\ y_t\end{bmatrix}\Bigm| y_{1:t-1}\sim
  \mathcal N\!\left(\begin{bmatrix}a_t\\ f_t\end{bmatrix},\ \begin{bmatrix}R_t & R_tF_t\\ F_t^\top R_t & Q_t\end{bmatrix}\right),
  \quad f_t=F_t^\top a_t,\ Q_t=F_t^\top R_t F_t + V_t.
  $$
  - **Update by Gaussian conditioning.** The conditioning formula (Ch. 3 / Ch. 5) for a joint Gaussian gives $\theta_t\mid y_{1:t}\sim\mathcal N(m_t,C_t)$ with
  $$
  m_t = a_t + A_t(y_t - f_t),\qquad C_t = R_t - A_t Q_t A_t^\top,\qquad A_t = R_t F_t Q_t^{-1}.
  $$
  The gain $A_t$ weights the innovation $y_t-f_t$ by how informative the observation is. This closes the induction: the filtered posterior is Gaussian at every $t$. $\blacksquare$
  - One sentence: with $(V,W)$ known these are exact closed-form updates — no sampling — the cleanest instance of conjugacy doing all the work.

### Task 4: Rungs 4–5 (smoother; Bayesian DLM) + Proof P2 (FFBS)

**Files:** Modify `parts/05-mmm-modeling/03-dlm.qmd`

- [ ] **Step 1: Write Rung 4 — the RTS smoother.** The filter uses only the past; the smoother revisits each state with the benefit of all data, $p(\theta_t\mid y_{1:T})$, via a backward recursion. State the update (for $G=I$): $B_t=C_t R_{t+1}^{-1}$, $m_t^s=m_t+B_t(m_{t+1}^s-a_{t+1})$, $C_t^s=C_t+B_t(C_{t+1}^s-R_{t+1})B_t^\top$. Note the full derivation is the P-tier exercise; the smoother is strictly tighter than the filter because it conditions on future observations.

- [ ] **Step 2: Write Rung 5 — Bayesian DLM and FFBS.** With priors on $(\theta_0,V,W)$, the full posterior covers states *and* variances. Present **FFBS** as "the Kalman filter you already know, run forward, then sampled backward": run the filter, draw $\theta_T$ from its filtered posterior, then draw each earlier $\theta_t$ from its backward conditional. Inside a Gibbs sampler, FFBS draws the state path given the variances, and conjugate inverse-gamma updates draw the variances given the path.

- [ ] **Step 3: Write Proof P2 — FFBS correctness.** State and prove:
  - **Factorization.** By the Markov structure of the state evolution, the joint smoothing posterior factors as
  $$
  p(\theta_{0:T}\mid y_{1:T}) = p(\theta_T\mid y_{1:T})\prod_{t=0}^{T-1} p(\theta_t\mid\theta_{t+1},y_{1:t}).
  $$
  (Given $\theta_{t+1}$, the state $\theta_t$ is independent of $y_{t+1:T}$ — future data act only through $\theta_{t+1}$.)
  - **Each factor is Gaussian.** $p(\theta_T\mid y_{1:T})=\mathcal N(m_T,C_T)$ is the final filtered posterior; and $p(\theta_t\mid\theta_{t+1},y_{1:t})$ is obtained by conditioning the filtered $\mathcal N(m_t,C_t)$ on the evolution equation $\theta_{t+1}=G_{t+1}\theta_t+w_{t+1}$ — a Gaussian conditioning yielding mean $m_t+B_t(\theta_{t+1}-a_{t+1})$ and variance $C_t-B_t R_{t+1} B_t^\top$.
  - **Conclusion.** Sampling $\theta_T$ then each $\theta_t$ backward draws an exact realization from $p(\theta_{0:T}\mid y_{1:T})$. $\blacksquare$

- [ ] **Step 1: Write Rung 6 — the conjugacy-vs-MCMC boundary.** State the lesson the chapter is built to teach: known variances give a closed-form posterior; unknown variances force sampling.

- [ ] **Step 2: Write Proof P3 — known variances ⇒ closed form; unknown ⇒ MCMC.** Prove:
  - **Known $(V,W)$.** By P1 the filtered posterior is exact and closed-form; the marginal likelihood factors through the one-step forecasts (the prediction-error / innovations decomposition)
  $$
  p(y_{1:T}) = \prod_{t=1}^{T} \mathcal N(y_t;\, f_t,\, Q_t),
  $$
  which can be maximized over $(V,W)$ — classical MLE, no sampling.
  - **Unknown $(V,W)$.** Placing priors on $(V,W)$ makes the joint posterior $p(\theta_{0:T},V,W\mid y)$ non-conjugate (the states and variances are coupled through $R_t,Q_t$). A Gibbs sampler restores tractability: FFBS draws $\theta_{0:T}\mid V,W,y$ (Gaussian, P2), and with inverse-gamma priors the conditionals $V\mid\theta,y$ and $W\mid\theta,y$ are inverse-gamma. This is exactly where conjugacy ends and MCMC begins — retroactively sharpening Part III. $\blacksquare$

**Files:** Modify `parts/05-mmm-modeling/03-dlm.qmd` (replace `## Code Tie-in` stub)

- [ ] **Step 2: Write the single `{python}` cell** (verified headless and reproducible — use exactly this):

```{python}
import numpy as np
import matplotlib.pyplot as plt

def kalman_filter(y, F, V, W, m0, C0):
    """Regression DLM: y_t = F_t theta_t + v (V); theta_t = theta_{t-1} + w (W). Scalar state."""
    T = len(y)
    m = np.zeros(T); C = np.zeros(T); a = np.zeros(T); R = np.zeros(T); f = np.zeros(T); Q = np.zeros(T)
    mt, Ct = m0, C0
    for t in range(T):
        at = mt; Rt = Ct + W                       # predict (G = 1)
        ft = F[t]*at; Qt = F[t]*Rt*F[t] + V        # one-step forecast
        A = Rt*F[t]/Qt                             # Kalman gain
        mt = at + A*(y[t] - ft); Ct = Rt - A*Qt*A  # update (Gaussian conditioning)
        m[t], C[t], a[t], R[t], f[t], Q[t] = mt, Ct, at, Rt, ft, Qt
    return m, C, a, R, f, Q

def rts_smoother(m, C, a, R):
    T = len(m); ms = m.copy(); Cs = C.copy()
    for t in range(T-2, -1, -1):
        B = C[t]/R[t+1]                            # G = 1
        ms[t] = m[t] + B*(ms[t+1] - a[t+1])
        Cs[t] = C[t] + B*B*(Cs[t+1] - R[t+1])
    return ms, Cs

def ffbs(y, F, V, W, m0, C0, rng):
    m, C, a, R, f, Q = kalman_filter(y, F, V, W, m0, C0); T = len(y); th = np.zeros(T)
    th[-1] = rng.normal(m[-1], np.sqrt(C[-1]))
    for t in range(T-2, -1, -1):
        B = C[t]/R[t+1]
        mean = m[t] + B*(th[t+1] - a[t+1]); var = C[t] - B*B*R[t+1]
        th[t] = rng.normal(mean, np.sqrt(max(var, 1e-12)))
    return th

# --- WE1: local-level steady-state Kalman gain = golden ratio ---
V0 = W0 = 1.0; C = 0.0; gain = 0.0
for _ in range(60):
    Rt = C + W0; Qt = Rt + V0; gain = Rt/Qt; C = Rt - gain*Qt*gain
assert abs(gain - (np.sqrt(5) - 1)/2) < 1e-5

# --- simulate a regression DLM with a drifting coefficient ---
rng = np.random.default_rng(17)
T = 600; V_true, W_true = 0.25, 0.04
x = np.abs(rng.normal(1.0, 0.4, T)) + 0.3
beta = np.zeros(T); beta[0] = 2.0
for t in range(1, T):
    beta[t] = beta[t-1] + rng.normal(0, np.sqrt(W_true))
y = beta*x + rng.normal(0, np.sqrt(V_true), T)

# --- WE2: filter and smoother (variances known) ---
m, C, a, R, f, Q = kalman_filter(y, x, V_true, W_true, 0.0, 10.0)
ms, Cs = rts_smoother(m, C, a, R)
rmse_f = np.sqrt(np.mean((m - beta)**2)); rmse_s = np.sqrt(np.mean((ms - beta)**2))
assert rmse_s < rmse_f

# --- WE3: known-variance log marginal likelihood (prediction-error decomposition) ---
loglik = np.sum(-0.5*np.log(2*np.pi*Q) - 0.5*(y - f)**2/Q)

# --- Bayesian DLM: Gibbs + FFBS recovers unknown (V, W) under weak IG(2, 0.01) priors ---
gr = np.random.default_rng(18); Vs, Ws = 1.0, 0.1; a0, b0 = 2.0, 0.01; draws = []
for it in range(4000):
    th = ffbs(y, x, Vs, Ws, 0.0, 10.0, gr)
    Vs = 1/gr.gamma(a0 + T/2,     1/(b0 + 0.5*np.sum((y - x*th)**2)))
    Ws = 1/gr.gamma(a0 + (T-1)/2, 1/(b0 + 0.5*np.sum(np.diff(th)**2)))
    if it > 1500: draws.append((Vs, Ws))
draws = np.array(draws); V_hat, W_hat = draws[:, 0].mean(), draws[:, 1].mean()
assert 0.5*V_true < V_hat < 2*V_true and 0.5*W_true < W_hat < 2*W_true

print(f"WE1 steady-state Kalman gain = {gain:.6f}  (golden ratio = {(np.sqrt(5)-1)/2:.6f})")
print(f"WE2 filter RMSE = {rmse_f:.4f}   smoother RMSE = {rmse_s:.4f}")
print(f"WE3 known-variance log marginal likelihood = {loglik:.2f}")
print(f"     Gibbs recovered V = {V_hat:.3f} (true {V_true}),  W = {W_hat:.4f} (true {W_true})")

fig, ax = plt.subplots(1, 2, figsize=(12, 4))
ax[0].plot(beta, "k-", lw=2, label="true β_t")
ax[0].plot(m, "C0-", alpha=0.7, label="filtered")
ax[0].plot(ms, "C1-", alpha=0.7, label="smoothed")
ax[0].set_title("time-varying coefficient"); ax[0].set_xlabel("t"); ax[0].legend()
ax[1].hist(draws[:, 0], bins=40, alpha=0.6, label="V")
ax[1].hist(draws[:, 1]*5, bins=40, alpha=0.6, label="W×5")
ax[1].axvline(V_true, color="C0", ls="--"); ax[1].axvline(W_true*5, color="C1", ls="--")
ax[1].set_title("variance posteriors (Gibbs)"); ax[1].legend()
plt.tight_layout()
plt.show()
```
